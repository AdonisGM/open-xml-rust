# Apache POI test documents

The Office documents in this directory are copied unmodified from the
`test-data` directory of the Apache POI project
(<https://github.com/apache/poi/tree/trunk/test-data>), which is distributed
under the Apache License, Version 2.0
(<https://www.apache.org/licenses/LICENSE-2.0>).

Apache POI — Copyright The Apache Software Foundation.

They are used only as test inputs: every XML part is read into the generated
schema types, written back and compared with the original.
