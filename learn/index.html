Học Rust qua dự án thật: open-xml-rust

Dự án này đọc và ghi file Word, Excel, PowerPoint bằng Rust, và được xây từ chính đặc tả ECMA-376. Khoá học đi lại con đường đó cùng bạn, từ file Cargo.toml đầu tiên đến API doc.add_paragraph(…). Bạn sẽ học Rust và Office Open XML song song, mỗi tầng code đi kèm đúng phần kiến thức cần cho tầng đó.

Dành cho: người mới học Rust cơ bản~286.000 dòng code, 12 crateHọc từ dưới lên

Cách học khoá này

  1. Đọc theo thứ tự. Bài sau dùng kiến thức bài trước. Mục lục bên trái (trên điện thoại thì bấm ☰) có dấu ✓ cho bài đã học.
  2. Mở code song song. Mỗi đoạn code thật đều ghi đường/dẫn/file.rs:dòng và có link sang GitHub. Tốt nhất là clone repo về máy rồi mở bằng VS Code (cài thêm rust-analyzer) để bấm "Go to definition".
  3. Tự gõ lại. Mỗi bài có phần 🛠 Bài tập. Đọc hiểu một lần không bằng tự gõ lại một lần.
  4. Trả lời phần "Tự kiểm tra" trước khi mở đáp án. Nếu sai, đọc lại đúng mục đó.
  5. Đừng cố hiểu 100% ngay. Lifetime hay macro thường phải gặp vài lần mới "ngấm". Bài học sẽ nói rõ chỗ nào có thể đọc lướt rồi quay lại sau.

Các hộp màu trong bài

📦 Góc OpenXML

Kiến thức về đặc tả ECMA-376: package, part, namespace, các thẻ w:p, mc:AlternateContent…, được đưa vào đúng lúc cần.

🦀 Góc Rust

Một khái niệm của ngôn ngữ, giải thích từ gốc.

🧩 Design pattern / kỹ thuật

Tên một kỹ thuật thiết kế đang được dùng (newtype, facade, builder, escape hatch…), vì sao dùng nó và khi nào bạn nên dùng.

💡 Mẹo

Mẹo thực hành, lệnh hữu ích.

⚠️ Chỗ hay nhầm

Những cái bẫy mà người mới hay rơi vào.

Lộ trình

Dự án được chia thành các tầng, tầng trên chỉ dùng tầng dưới. Khoá học đi từ dưới lên: tầng dưới nhỏ và ít phụ thuộc nên hợp để học Rust cơ bản, càng lên cao code càng lớn nhưng lúc đó bạn đã có nền.

Phần 6 openxml-docx / xlsx / pptx API thân thiện cho người dùng
Phần 5, 7 openxml-core · openxml-chart · CLI phần dùng chung, dòng lệnh, test
Phần 4 openxml-codegen → openxml-schema sinh 215.000 dòng code từ XSD
Phần 3 openxml-opc ZIP, part, relationship
Phần 2 openxml-xml đọc/ghi XML có namespace
Phần 0–1 Nền móng OpenXML là gì, công cụ, cấu trúc dự án

Phần 0 · Khởi động

Mổ một file .docx, cài công cụ, đi một vòng quanh dự án.

Phần 1 · Cấu trúc dự án

Cargo workspace, crate, module, pub, kiến trúc phân tầng, facade.

Phần 2 · Tầng XML

Newtype, macro, xử lý lỗi, lifetime, Cow, trait, generic, cấu trúc dữ liệu đệ quy.

Phần 3 · Đóng gói OPC sắp có

ZIP, PartName, content type, relationship.

Phần 4 · Sinh code sắp có

XSD → IR → Rust: một "compiler" nhỏ.

Phần 5–8 sắp có

Core, API tài liệu (builder, view), chart, CLI, test, tự viết mini-openxml.

Bạn cần chuẩn bị gì?

  • Đã đọc qua vài chương đầu của The Rust Programming Language (hoặc bản dịch tiếng Việt): biến, hàm, struct, enum, match. Chưa vững cũng không sao, khoá học sẽ ôn lại khi cần.
  • Một máy tính có thể cài Rust (bài 0.2 hướng dẫn).
  • Clone repo: git clone https://github.com/AdonisGM/open-xml-rust
